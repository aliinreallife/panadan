روش اتصال را متناسب با محیط خود انتخاب کنید؛ هیچ‌گاه توکن را داخل Git ذخیره نکنید. برای REST API از صفحهٔ راهنمای API استفاده کنید.

۱. ساخت توکن اختصاصی

از بخش توکن‌های دسترسی یک توکن با نوع mcp:read بسازید و آن را یک‌بار کپی کنید. توکن‌ها قابل لغو و دارای تاریخ انقضا هستند.

۲. اتصال روی همین دستگاه

آدرس محلی MCP در حال اجرا:

{{base_url}}{{mcp_path}}

این آدرس فقط از همین دستگاه در دسترس است. نرم‌افزارهایی مثل Cursor و کلاینت‌های MCP با قابلیت درج هدر Authorization می‌توانند از آن استفاده کنند.

{
  "url": "{{base_url}}{{mcp_path}}",
  "headers": {
    "Authorization": "Bearer YOUR_MCP_TOKEN"
  }
}

۳. اتصال OAuth به ChatGPT و سایر کلاینت‌ها

سرویس پانادان اکنون در حالت OAuth قرار دارد. توکن‌های امضاشده توسط ارائه‌دهندهٔ هویت تأیید و به کاربر مجاز متصل می‌شوند.

برای فعال‌شدن اتصال ChatGPT، ارائه‌دهندهٔ هویت باید Authorization Code + PKCE، کشف خودکار و ثبت کلاینت سازگار را پشتیبانی کند؛ آدرس سرویس OAuth نیز باید از طریق HTTPS امن در دسترس باشد.

۴. اتصال پس از دریافت دامنه

پس از راه‌اندازی HTTPS، آدرس اتصال مانند https://your-domain.example/mcp/ خواهد بود. قبل از انتشار عمومی باید پیکربندی OAuth ارائه‌دهنده، کنترل Host/Origin، HTTPS، محدودیت درخواست، لاگ‌های امنیتی و جریان کامل اتصال بررسی شوند.
