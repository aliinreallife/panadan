اتصال MCP

روش اتصال را متناسب با محیط خود انتخاب کنید؛ هیچ‌گاه توکن را داخل Git ذخیره نکنید. برای REST API از صفحهٔ راهنمای API استفاده کنید.

۱. ساخت توکن اختصاصی

از بخش توکن‌های دسترسی یک توکن با نوع mcp:read بسازید و آن را یک‌بار کپی کنید. توکن‌ها قابل لغو و دارای تاریخ انقضا هستند.

۲. اتصال روی همین دستگاه

آدرس محلی MCP در حال اجرا:

{{base_url}}{{mcp_path}}

این آدرس فقط از همین دستگاه در دسترس است. نرم‌افزارهایی مثل Cursor و کلاینت‌های MCP با قابلیت درج هدر Authorization می‌توانند از آن استفاده کنند.

{
  "url": "{{base_url}}{{mcp_path}}",
  "headers": {
    "Authorization": "Bearer YOUR_MCP_TOKEN"
  }
}

۳. اتصال ChatGPT

برای ChatGPT Hosted، آدرس localhost مستقیماً در دسترس نیست. پیش از اتصال باید یک Secure MCP Tunnel یا یک نقطهٔ دسترسی امن HTTPS داشته باشید؛ نیازی نیست همین امروز دامنه بخرید.

علاوه بر دسترسی شبکه، برای جریان اتصال کاربرمحور ChatGPT باید OAuth پشتیبانی شود. نسخهٔ فعلی فقط توکن Bearer دستی دارد و نباید به‌عنوان OAuth سازگار معرفی شود. این قابلیت در مرحلهٔ بعدی توسعه است.

۴. اتصال پس از دریافت دامنه

پس از راه‌اندازی HTTPS، آدرس اتصال مانند https://your-domain.example/mcp/ خواهد بود. برای انتشار عمومی باید OAuth 2.1، کنترل CORS/Origin، محدودیت درخواست و ثبت رویدادهای امنیتی تکمیل شوند.
