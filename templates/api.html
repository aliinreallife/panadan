راهنمای REST API

از داده‌های مجاز تماس‌ها در برنامه‌های دیگر استفاده کنید؛ بدون امکان تغییر اطلاعات منبع.

مشاهده مستندات تعاملی ↗
۱

دریافت توکن

در توکن‌های دسترسی، نوع api:read را انتخاب کنید. برای جزئیات حساس، مجوز و توکن جداگانه لازم است.

۲

ارسال درخواست

در هدر درخواست، Authorization: Bearer را همراه توکن اختصاصی خود ارسال کنید.

۳

دریافت JSON

پاسخ‌های API فقط خواندنی‌اند. تاریخ‌ها به‌صورت ISO 8601 هستند، نه شمسی.

آدرس پایه

آدرس محلی برای همین دستگاه؛ از اینترنت عمومی در دسترس نیست.

{{base_url}}/api/v1

کلید دسترسی را در کد سمت مرورگر، آدرس URL، مخزن Git یا لاگ‌ها قرار ندهید. استفاده در سرور یا ابزار شخصی امن انجام شود.

نمونه درخواست

ترمینال · curl

به‌جای YOUR_REST_TOKEN توکن خود را در محیط امن قرار دهید. این مثال برای اجرای محلی است.

curl --fail-with-body \
  -H 'Authorization: Bearer YOUR_REST_TOKEN' \
  '{{base_url}}/api/v1/calls?limit=20&call_type=FollowUp&state=Unchecked'

پارامترهای پرکاربرد

limit۱ تا ۱۰۰؛ تعداد رکورد
offsetشروع صفحه‌بندی (از صفر)
after / beforeتاریخ میلادی ISO مانند 2026-10-29
call_typeمقدار خام نوع تماس مانند FollowUp یا FirstToch
stateمقدار خام وضعیت مانند Unchecked یا SoldOut

برچسب‌های فارسی در داشبورد فقط برای نمایش‌اند. در API مقدار خام ارسال می‌شود. برچسب SoldOut لزوماً تأیید فروش قطعی نیست.
