اتصال OAuth فعلاً غیرفعال است. برای آماده‌سازی، از یک سرویس هویت OAuth 2.1 سازگار با Authorization Code + PKCE و ثبت کلاینت (CIMD، DCR یا کلاینت ازپیش‌ثبت‌شده) استفاده کنید.

تا زمان راه‌اندازی HTTPS و ارائه‌دهندهٔ هویت، اتصال دستی MCP روی همین دستگاه ادامه پیدا می‌کند. فقط تنظیمات ارائه‌دهنده را در فایل خصوصی .env.app قرار دهید؛ هیچ‌گاه رمز، کلید یا توکن را در Git ذخیره نکنید.

این صفحه به‌معنای تکمیل اتصال ChatGPT نیست. اتصال نهایی به پیکربندی OAuth ارائه‌دهنده، HTTPS، قابلیت دسترسی خارجی و تست عملی نیاز دارد.

محدودهٔ دسترسی

دستیارها فقط ابزارهای گزارش‌گیری غیرحساس را دریافت می‌کنند. متن خام مکالمات، اطلاعات حساس مشتری و عملیات ویرایشی از طریق MCP در دسترس نیستند. نقش و مجوز هر کاربر در هر درخواست دوباره بررسی می‌شود.
